# terminal

Shared Ghostty + Zellij configs (keybindings etc.) and matched color themes in a "medieval/renaissance meets modern computing" style (aged pigments, gold, ink; no rainbow), plus `term-theme` to switch both at once. Configs and themes are shared across machines; the active theme is chosen per machine.

## Install on a machine

Requires a checkout at `~/Tools/nicnajder-general-utils` (any path works, the script resolves its own location), Ghostty >= 1.2, Zellij >= 0.45, and `~/.local/bin` on `PATH`.

```bash
~/Tools/nicnajder-general-utils/install.sh terminal    # or terminal/install.sh directly
term-theme manuscript
```

`install.sh --check terminal` reports what differs from the repo without changing anything. `install.sh` symlinks into the checkout:

| repo | linked as |
|---|---|
| `ghostty/config.ghostty` | `~/.config/ghostty/config.ghostty` |
| `zellij/config.kdl` | `~/.config/zellij/config.kdl` |
| `ghostty/themes/*` | `~/.config/ghostty/themes/*` |
| `zellij/themes/*` | `~/.config/zellij/themes/*` |
| `zellij/layouts/*` | `~/.config/zellij/layouts/*` |
| `zellij/plugins/*` | `~/.config/zellij/plugins/*` |
| `term-theme` | `~/.local/bin/term-theme` |

Anything in the way is moved to `backups/<date>_<time>/` in the checkout, never overwritten. The script is idempotent: re-run it after a `git pull` that adds new files. Edits to existing files need no re-run, the symlinks already point into the checkout. On first install it activates `gold-dim`.

## Per-machine theme

The shared configs never contain the theme, so switching never dirties the repo:

- `config.ghostty` includes `config-file = ?local.ghostty` (Ghostty reads included files after the main one, so local values win); `term-theme` writes `theme = ...` into the untracked `~/.config/ghostty/local.ghostty`. Other machine-specific Ghostty settings (font size, ...) can go there too.
- `config.kdl` uses `theme "active"`; `term-theme` writes the untracked `~/.config/zellij/themes/active.kdl`, a copy of the chosen theme renamed to `active`, with a `// term-theme: <name>` first line recording the choice.

## Editing the configs

Edit the files in the checkout (or through the symlinks) and commit. If Zellij's in-app configuration screen saves `config.kdl`, check with `ls -l ~/.config/zellij/config.kdl` that it is still a symlink; if Zellij replaced it with a regular file, copy it over `zellij/config.kdl`, restore `theme "active"`, drop the autogenerated header, and re-run `install.sh`.

## Usage

```bash
term-theme                  # list themes, * marks the active one
term-theme next             # rotate within the active group (light or dark)
term-theme venetian-dark    # pick one by name; "dark" is an alias for gold-dim
```

Both apply live: Ghostty reloads on `SIGUSR2`, Zellij reloads when `themes/active.kdl` changes.

```bash
zellij -l vtabs             # tab list in a left sidebar instead of the top tab bar
```

`layouts/vtabs.kdl` runs `plugins/zellij-vertical-tabs.wasm`, the `v0.1.0` release of [cfal/zellij-vertical-tabs](https://github.com/cfal/zellij-vertical-tabs) (MIT). On first launch Zellij asks for the plugin's permissions: focus the sidebar and press `y`. `Alt s` toggles the sidebar selectable, so it can be focused and resized. Its colors are fixed to `gold-dim` and do not follow `term-theme`. To upgrade, replace the `.wasm` with a newer release and commit.

## Themes

Ghostty file `royal-<name>`, Zellij theme `royal-<name>`.

| name | group | feel |
|---|---|---|
| `manuscript` | light | rich: vellum, iron-gall ink, vermilion, lapis, gold leaf |
| `venetian` | light | rich: ivory, burgundy, Medici green, ochre |
| `library` | light | muted: linen, sepia, brass, bottle green, oxblood |
| `stone` | light | muted, cool: limestone, slate, pewter, muted gold |
| `manuscript-dark` | dark | rich: oak-ink ground, vellum text, gold leaf, vermilion, lapis |
| `venetian-dark` | dark | rich: wine-black, ivory, crimson, Medici green, ochre |
| `library-dark` | dark | muted: dark leather, parchment text, brass, bottle green |
| `stone-dark` | dark | muted, cool: slate, pewter text, muted gold, slate blue |
| `gold-dim` | dark | Ghostty's built-in `Adventure` + Zellij `gold-dim` (black, gray text, muted gold) |

Body text contrast is 11-15:1 against the background and the normal ANSI colors (1-6) are around 4.5:1 or better, so `ls`, git and prompts stay readable. Zellij themes all share the same component layout: focused frame and active tab use the theme's main accent, unfocused frames recede toward the background.

## Adding a theme

Add `ghostty/themes/royal-<name>` and `zellij/themes/royal-<name>.kdl` (Zellij theme block named `royal-<name>`), append `<name>` to `LIGHT` or `DARK` in `term-theme`, then re-run `install.sh`.
